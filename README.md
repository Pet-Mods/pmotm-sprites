# Pet Mod replacement sprites
A simple Tampermonkey plugin for rendering Pet Mod sprites on Pokemon Showdown in battles and replays.

Requirements: [Tampermonkey Chrome extension][1], working brain

[1]: https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo

When installing, ignore the errors that appear. It works because the definitions are handled in the site itself.

The list of species names is maintained by me (iforgetwhyimhere) here in `replacements.txt`.

## How to install

1) Open Tampermonkey.

2) Go to **Utilities**.

3) Under "Import from URL", paste the following link:
https://raw.githubusercontent.com/Pet-Mods/pmotm-sprites/refs/heads/main/plugin.js

4) Click **Install**.

5) Refresh your Pokemon Showdown page, if open.

To automatically recieve updates, go to Tampermonkey, then:

1) Open the plugin.

2) At the top, switch "Editor" to "Settings".

3) Scroll down to **Updates**.

4) In **Update URL**, paste the same link as above.

5) Click **Save**.

6) To check for updates, open the Tampermonkey extension panel from your browser, then select **Utilities** and **Check for userscript updates**.
